# 🌿 오늘의 마음 (Daily Mind) | 감정 일기 & TO-DO 동기화 Web App

> **"잘 정리해서 쓰지 않아도 괜찮아요. 지금 느끼는 마음 그대로 적어보세요."**  
> 오늘의 마음은 일상 속 감정 기록, 공부 스케줄, 랜덤 질문 답변을 한곳에서 관리하고 Firebase를 통해 **TO-DO LIST와 실시간 동기화**되는 싱글 페이지 감정 일기 웹 애플리케이션입니다.

---

## 📸 미리보기 (Preview)

- **디자인 컨셉**: 눈이 편안한 네이처 톤(Soft Sage Green) & 반응형 카드 레이아웃
- **기술 스택**: Vanilla HTML5, CSS3, JavaScript (ES6+), Firebase v10 (Authentication & Firestore)
- **배포 방식**: GitHub Pages / Netlify 등 단일 HTML 파일 배포 지원

---

## ✨ 주요 기능 (Key Features)

### 1. 🎭 오늘 나의 감정 선택 (Multi-select Moods)
- 행복, 평온, 피곤, 불안, 과부하, 번아웃 등 **17가지 이상의 세분화된 감정 태그** 제공
- 복수 선택 지원으로 다채로운 나의 마음 상태를 입체적으로 기록

### 2. 📝 자유로운 일기 & 공부 기록 (Journal & Study Log)
- **실시간 글자 수 카운팅** 지원
- 공부 일지, 학습 중 느낀 점, 추가 메모를 위한 별도의 **공부 기록 전용 영역** 탑재
- 작성 중 데이터 손실 방지를 위한 **자동 저장(Debounce Save)** 탑재

### 3. 🌿 오늘의 질문 (Daily Reflection Prompts)
- 감정, 돌봄, 성장, 관계, 공부, 생각, 미래 등 **20가지 심리·회고 질문 카드로 무작위 제공**
- 질문 추첨(`다른 질문 뽑기`) 및 답변 기록 기능

### 4. ✅ 기존 TO-DO LIST와 실시간 연동 (Firebase Cloud Sync)
- 동일한 Firebase 계정으로 로그인 시, **기존 TO-DO LIST 앱의 해당 날짜 할 일 목록 자동 불러오기**
- 기기 간(모바일/PC) 일기 데이터 실시간 Cloud 동기화 (`Firestore`)

### 5. 📅 감정 달력 & 검색 (Calendar & Search)
- **감정 달력**: 일기가 작성된 날짜에 초록색 인디케이터(점) 표시 및 해당 날짜 클릭 시 기록으로 즉시 이동
- **실시간 통합 검색**: 키워드 입력 시 감정 태그, 일기 내용, 공부 기록, 질문 답변까지 한꺼번에 검색

### 6. 🔒 데이터 백업 & 개인정보 보호
- **백업 내보내기/불러오기**: `.json` 포맷 데이터 백업 및 복원 기능 제공
- **로컬 & 클라우드 이중 저장**: 오프라인 상태에서는 `localStorage`로 안전하게 보관

## 🛠️ 서비스 개선일지 (Service Improvement Log)

> 일상 속 감정과 학습 회고를 기록하며 발견한 **사용자 불편(Pain Point)**을 정의하고, **기록 진입 장벽 완화·탐색 UX·외부 서비스 데이터 연동** 관점에서 고도화한 기록입니다.

### ① [UX/콘텐츠] 다중 감정 태그(17종+) 셀렉터 및 랜덤 회고 질문(20종) 도입
* **문제 인식 (Pain Point):** 하루의 복합적인 감정을 단일 아이콘으로 표현하기 어려웠고, 빈 입력창 앞에서 무엇을 써야 할지 막막해 기록을 포기하는 심리적 진입 장벽(Blank Page Syndrome)이 발생함.
* **해결 및 구현 (Action):** 17가지 이상의 세분화된 감정 키워드를 동시에 선택·해제할 수 있는 커스텀 무드 셀렉터와, 7개 카테고리·20가지 심리·회고 질문 카드에서 무작위 질문을 제시하는 `다른 질문 뽑기` 기능을 탑재함.
* **기획적 기대 효과 (Result):** 기록 시작의 심리적 부담을 낮춰 지속적인 작성 습관을 유도하고, 비정형 감정을 정형화된 태그 데이터로 축적할 수 있는 기반을 마련함.

### ② [정보 구조] 감정·학습 통합 기록 및 감정 달력·통합 키워드 검색 고도화
* **문제 인식 (Pain Point):** 일기와 학습 회고를 따로 관리해 하루의 감정과 학업 성취의 연관성을 돌아보기 어려웠고, 데이터가 쌓일수록 과거 특정 기록을 다시 찾기 힘들었음.
* **해결 및 구현 (Action):** 동일 날짜 내에 감정 일기와 '공부 기록 전용 영역'을 함께 저장하도록 데이터 스키마를 통합하고, Soft Sage Green 톤 UI 리뉴얼과 함께 작성일 인디케이터가 표시되는 감정 달력 뷰·전 영역 통합 키워드 검색 기능을 구현함.
* **기획적 기대 효과 (Result):** 감성적 톤앤매너와 탐색 효율성을 동시에 확보하여, 단순 일회성 메모장을 넘어 축적된 개인 기록을 입체적으로 회고(Review)하는 데이터 아카이브로 발전시킴.

### ③ [시스템 연동] TO-DO LIST 데이터 자동 연동 및 Firebase 통합 계정 운영
* **문제 인식 (Pain Point):** 별도로 운영하던 `TO-DO LIST`의 완료 내역을 일기에 다시 수기로 옮겨 적는 중복 입력 불편이 발생했으며, PC와 모바일 간 일기 데이터 실시간 동기화가 필요했음.
* **해결 및 구현 (Action):** `TO-DO LIST`와 동일한 Firebase v10 계정 체계를 공유하도록 설계하고, 해당 날짜의 할 일 목록과 완료 상태를 Firestore에서 실시간 구독해 일기 화면에 자동 표시(수정은 원본 앱으로 역할 분리)하도록 연동함.
* **기획적 기대 효과 (Result):** 중복 입력을 제거하고 개별 웹앱들을 하나의 통합 개인 관리 생태계로 연결함으로써, **서비스 간 데이터 파이프라인 설계 및 크로스 앱 UX 통합 역량**을 실증함.

### ④ [데이터 안정성] Debounce 자동 저장 및 JSON 백업·로컬 이중 저장 구축
* **문제 인식 (Pain Point):** 긴 회고 글을 작성하던 중 저장 버튼을 누르지 않고 페이지를 이탈하거나 네트워크가 불안정할 경우 기록이 유실될 위험이 있었음.
* **해결 및 구현 (Action):** 사용자 입력 및 페이지 종료 이벤트를 감지하는 디바운스 자동 저장(Debounce Save)과 `localStorage`·Firestore 이중 저장 구조를 적용하고, 데이터 형식 검증을 거치는 `.json` 백업 내보내기·불러오기 기능을 추가함.
* **기획적 기대 효과 (Result):** 수동 저장의 번거로움과 데이터 유실 불안을 해소하여 사용자가 온전히 기록과 성찰에만 몰입할 수 있는 안정적인 환경을 제공함.
